# 模块入口与 UI 锚点

淘宝改版频繁，锚点**以文案匹配为主、位置为辅**。都找不到时走文末「降级路径」。坐标实测基准：1176×2400。

## 通用前置

1. `mobile_launch_app` 冷启动 `com.taobao.taobao`。
2. 关掉开屏广告 / 摇一摇 / 红包弹层 / 升级提示，只点「跳过」「关闭」或 X。
3. 冷启动默认落在**首页**，目标入口多半就在金刚区——**先在首页找一轮，找不到再切「我的淘宝」**。
4. ⚠️ **冷启动也可能落在「频道页」**：没有底部 Tab、左上「←」、底部有「回到首页」（中心 ≈ (588,2286)）。先点「回到首页」，别在频道页里翻入口。

## 首页金刚区（优先入口）

首屏搜索栏下方那一行（y≈343）就是目标区，金刚区不在首屏就向下滑 1~2 屏，**最多 2 屏**（再往下是商品 feed，放弃首页路线）。

| 入口 | 节点特征 | 容器 / 点击点 |
|---|---|---|
| 领淘金币 | content-desc `label="领淘金币"` | `at=28,343 191x201`，中心 ≈ (123,443) |
| 芭芭农场 | content-desc `label="芭芭农场"` | `at=640,343 191x201`，中心 ≈ (735,443) |
| 红包签到 | content-desc `label="红包签到"` | `at=436,343 191x201`，中心 ≈ (531,443) |

- 这三个入口在可访问性树里是 **content-desc（`label=`），没有 `text=`**，匹配时两个字段都要看，只 grep `text` 会漏。
- ⚠️ **金刚区一律坐标点击，禁止 ref**：入口有两层完全重叠的同 label `FrameLayout`，ref 点击会点到别的入口（实测点到了「天猫汽车」小程序）。点完立刻 list 校验落点；连错 2 次改走「我的淘宝」。
- 首页下半屏全是商品 feed 与「立即领取」优惠券横幅，**只点 label/text 精确等于目标入口的元素**，禁止点商品卡、红包横幅、任何模糊匹配文案。
- 落地校验：芭芭农场 → `WebView text="芭芭农场"`；淘金币 → `WebView text="淘金币首页"`；红包签到 → `TMSActivity` + 「红包签到·领现金」。落点不对 BACK 回首页重试一次。
- 两个模块落地页右上角有「返回首页」（`id=back_home_btn`），回首页用它比连按 BACK 稳。

## 芭芭农场

1. 首页金刚区「芭芭农场」→ **坐标点击** → list 校验落到 `WebView text="芭芭农场"`。
2. 点「**集肥料**」（同义锚点：「做任务」「去集肥料」「肥料任务」）→ 任务列表。

兜底（「我的淘宝」）：Tab 切「我的淘宝」→ 下滑 1~2 屏找「芭芭农场 / 农场」或副标题含「免费领水果 / 种水果 / 浇水」→ `sleep 3` 等 H5 加载 → 点「集肥料」。

任务列表特征：「集肥料」「今日任务」「浏览 XX 秒」「去浏览」「已领取」「去完成」。

## 淘金币

1. 首页金刚区「领淘金币」→ **坐标点击** → list 校验落到 `WebView text="淘金币首页"`（页内能读到金币余额）。
2. 点「**赚更多金币**」→ 任务列表。两侧还有「玩游戏」「找好友」，**不要点**。

兜底（「我的淘宝」）：找「淘金币 / 金币」或副标题含「签到 / 领金币 / 当钱花」，也可能在顶部「我的资产」或「更多工具」九宫格里 → 点「赚更多金币」。

任务列表特征：「赚更多金币」「每日任务」「浏览 XX 秒」「去浏览」「签到」「已领取」。

## 双十一赛车活动（临时模块，仅用户主动触发）

⚠️ 与「淘金币」模块**共用前两段入口，第三段分岔**：淘金币点「**赚更多金币**」，赛车点「**去赚能量**」。点错就进了另一个模块的任务列表。完整流程、判定补充表与实测值见 `temp-double11-race.md`。

1. 首页「领淘金币」→ 坐标点击 → 校验 `WebView text="淘金币首页"`。
2. 找「**去赚能量**」：`Button text="去赚能量" id="energy_task_button" at=933,948 246x162`，中心 **(1056,1029)**。**必须坐标点击**——ref 会点到正上方 y=828 的「组队赢」（落到 PK 页）。
   - 首次点击常先弹「搜索商品得能量最高600」活动弹窗：点它的 X ≈ (588,1920) 关掉，回淘金币首页**再点一次**才出任务弹层。别把第一次没出列表判成失败。
   - 找不到时顺序：list 文案匹配 → 下滑 1~2 屏再 list → adb 截图看图定位 → 放弃并汇报，建议移除本模块。

返回落点四种都正常（任务列表 / 赛车主页 / 淘金币首页 / 首页金刚区），按落点重进，**不要连按 BACK**。

## 淘宝签到（红包签到 · 赚元宝）

> 仅用户主动触发，默认运行不含本模块。实测基准：LIO-AN00，1176×2400。

1. 首页金刚区「红包签到」→ 坐标 **(531,443)** 点击（content-desc、双层重叠 → 必须坐标）→ `sleep 3`。
2. 校验落地 `TMSActivity` + 「红包签到·领现金」，页内数字锚点（list 直接读）：
   - `Button id="ACCOUNT_CASH_VALUE"` text「1.82元」= 现金余额（锚点①）
   - `Button text="再攒NNNNN元宝提现"`（锚点②，最可靠）：每完成一轮按奖励额减少
   - `TextView text="连续签到奖励(18/28)"` = 签到进度
   - `Button id="EARN_YUANBAO_BUTTON"` text「+NNNNN元宝，赚元宝」`at=60,879 198x192`，中心 **(159,975)** → 点它拉起任务弹层
3. ⚠️ 签到主页**只点「赚元宝」**。其余一概不碰：「继续领钱 / 明日再来 / 开启提醒」、底部横排入口（返现金、折扣红包、点击领取、**看书赚钱**、**去蚂蚁农场**、省钱包、攒钱提现、芭芭农场、花园世界 / 末世王者 = 游戏）。签到领钱本身不在本模块职责内。
4. 弹层校验：顶栏 `TextView text="做任务赚元宝"` + 左上「已攒」+ 右上 `Button text="关闭"` 中心 ≈ (1101,769)。

兜底：底部 Tab「我的淘宝」→ 找「红包签到」（副标题含「签到 / 领现金」）→ 赚元宝。

### 弹层（做任务赚元宝）机制

- **dump 不冻结**（与芭芭农场/赛车弹层相反）：滑动后 list 正常刷新，可直接 list + ref/坐标点击。
- ⚠️ **行可滚到 sticky header 上方**：顶栏固定在 y≈693~846，**y < 693 的行视觉不可见**，点它们的坐标会落在弹层外的背景页、把弹层整个点没（重开即可：BACK 回主页再点「赚元宝」，列表状态不丢）。**只点 y ≥ 850 的行按钮**；目标行在上方就先往回滑。
- 按钮列 `at=996,y size=126x51` → **中心 x≈1059**；普通行高 ~213px，带第三行副标题（如「边逛边赚」）~249px。首行按钮中心 ≈ (1059,961)，第二行（好物沉浸看）≈ (1059,1204)。
- 「已攒 NNNN」在 dump 里读不到（滚动动画，`text` 恒为 `"0123456789"`）：判入账优先用任务行 `(n/N)`，其次 BACK 后读主页「再攒 NNNNN 元宝提现」的差值。
- **到底判据**：出现 footer「**- 以上奖励均为最高奖励，以实际获得奖励为准 -**」，不需要比图。一屏约 7 行，全列表 ~17 行，下滑 2~3 次遍历完。
- 执行与返回完全沿用主流程阶段 3（三个子类分流照旧）。本模块 BROWSE 通常 3~4 个槽位，一般 10~20 分钟收敛。

## 小黑盒集钥匙

入口是 deeplink，不走金刚区：`adb shell am start -a android.intent.action.VIEW -d "https://m.tb.cn/h.jVRERsc" com.taobao.taobao` → 落地 `WebView text="开盒有喜-线上"` → 点「做任务集钥匙」（无文本节点，中心 ≈ (789,550)）拉起任务弹层。完整流程见 `blackbox-keys.md`。

## 找不到入口时的降级路径

按序尝试，成功即停（入口来源记进首个任务的 `--note`，方便复盘首页直入命中率）：

1. **首页金刚区**：停首页，在首屏及下滑 1~2 屏内找目标入口。
2. **我的淘宝**：Tab 切过去，下滑 1~2 屏，入口可能藏在「更多工具」九宫格第二页。
3. **展开更多**：有「更多 / 全部工具 / 查看全部」就点开在九宫格里找。
4. **搜索兜底**：回首页点搜索框 → `mobile_type_keys` 输入「芭芭农场 / 淘金币 / 红包签到」并 `submit: true` → 点官方卡片或「立即进入」。
5. **放弃**：记录「入口未找到 + 当前页面元素摘要」，跳下一个模块。**不要用 `mobile_open_url` 拼不确定的 scheme。**

## H5 容器注意

农场 / 金币 / 签到都是 Webview 或小程序容器：

- list 可能只返回少量元素甚至只有根节点——**多半是页面还没渲染完**，等一轮再 list 通常就完整了（淘金币首页的 dump 实测完整：`@e36 WebView text="淘金币首页"`、余额 `text="1137594"`、`text="赚更多金币" at=300,585 576x150` 都直接可读）。真正需要截图的只有「任务列表弹层内部滚动」那一种，见 `mobile-mcp-playbook.md` 的「dump 过期的确切边界」。
- 加载期症状：白屏、只有标题栏、元素列表为空 → 等 3 秒重试，最多三轮。
- 容器内的返回箭头点不动时，改用 `mobile_press_button` BACK。
- 可能自动弹「领取今日奖励」「开屏福利」浮层 → 找 X 关掉，**不要**点浮层中心的按钮（多半是「去下单」「去抢购」）。

## 回到任务列表

1. 连按 BACK，**每按一次 list 一次**，判断是否出现模块锚点。锚点同时接受上一层：`WebView text="淘金币首页"` / `WebView text="芭芭农场"`（回模块主页，再点「集肥料 / 赚更多金币」即可），或首页金刚区 `label="领淘金币"` / `label="芭芭农场"`（按入口顺序重进）。
2. 回到哪层就走哪层的路径重进，**不必执着于回到任务列表弹层**——从模块主页进和从首页直入等价。
3. 最多 5 次；超过则 `mobile_launch_app` 重启淘宝，停在首页重进。
4. 重进后列表可能已重排，**重新 list 再继续**。
