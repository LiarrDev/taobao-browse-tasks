# 模块入口与 UI 锚点

淘宝版本迭代会调整 UI，以下锚点按**文案匹配**为主、**位置**为辅。所有锚点都可能变动，找不到时按末尾的降级路径处理。

## 通用前置

1. 冷启动：`mobile_launch_app` 包名 `com.taobao.taobao`
2. 关掉开屏广告 / 摇一摇 / 红包弹层 / 升级提示，只点「跳过」「关闭」或 X
3. 底部 Tab 通常五个：首页、微淘/逛逛、消息、购物车、我的淘宝。**目标入口在「我的淘宝」**

## 芭芭农场

路径（主）：

1. 底部 Tab 点「我的淘宝」
2. 在「我的淘宝」页向下滑 1~2 屏，寻找含以下文案的入口：
   - 「芭芭农场」
   - 「农场」
   - 副标题含「免费领水果」「种水果」「浇水」
3. 点击进入 → 等待 H5 容器加载（`sleep 3`，必要时再来一轮）
4. 进入后点「**集肥料**」（同义锚点：「做任务」「去集肥料」「肥料任务」）→ 弹出/跳转到任务列表

任务列表页特征锚点：「集肥料」「今日任务」「浏览 XX 秒」「去浏览」「已领取」「去完成」。

## 淘金币

路径（主）：

1. 底部 Tab 点「我的淘宝」
2. 寻找含以下文案的入口：
   - 「淘金币」
   - 「金币」
   - 副标题含「签到」「领金币」「当钱花」
   - 也可能在顶部「我的资产」区域或「更多工具」九宫格里
3. 点击进入 → 等待加载
4. 进入后点「**赚更多金币**」（同义锚点：「做任务赚金币」「赚金币」「去赚金币」）→ 打开任务列表

任务列表页特征锚点：「赚更多金币」「每日任务」「浏览 XX 秒」「去浏览」「签到」「已领取」。

## 找不到入口时的降级路径

按顺序尝试，任一环节成功即停止：

1. **换屏下滑**：我的淘宝往下再滑 1~2 屏，入口可能藏在「更多工具」九宫格第二页
2. **展开更多**：若页面有「更多」「全部工具」「查看全部」，点开后在九宫格里找
3. **搜索兜底**：点顶部搜索框 → `mobile_type_keys` 输入「芭芭农场」或「淘金币」（带 `submit: true`）→ 在结果中点对应的官方卡片 / 「立即进入」按钮
4. **放弃**：三种都失败 → 记录「入口未找到 + 当前页面元素摘要」，跳到下一个模块。不要用 `mobile_open_url` 拼不确定的 scheme

## H5 容器注意事项

两个模块基本都是 Webview / 小程序容器，因此：

- `mobile_list_elements_on_screen` 可能只返回少量元素甚至只有根节点；此时配合 `mobile_take_screenshot` 用坐标点击
- 加载期间的症状：白屏、只有标题栏、元素列表为空 → 等待 3 秒后重试，最多三轮
- 容器内的返回箭头点不动时，改用 `mobile_press_button` BACK
- 页面可能自动弹出「领取今日奖励」「开屏福利」浮层 → 找 X 关掉，**不要**点浮层中心的按钮（多半是「去下单」「去抢购」）

## 回到任务列表

完成一个任务后：

1. 连按 BACK，每按一次 list 一次，判断是否出现模块锚点文案
2. 最多 5 次；超过则 `mobile_launch_app` 重启淘宝，重走「我的淘宝 → 入口 → 集肥料 / 赚更多金币」
3. 注意：重进后列表可能已重排，重新 list 再继续
