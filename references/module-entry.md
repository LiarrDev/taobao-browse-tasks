# 模块入口与 UI 锚点

淘宝版本迭代会调整 UI，以下锚点按**文案匹配**为主、**位置**为辅。所有锚点都可能变动，找不到时按末尾的降级路径处理。

## 通用前置

1. 冷启动：`mobile_launch_app` 包名 `com.taobao.taobao`
2. 关掉开屏广告 / 摇一摇 / 红包弹层 / 升级提示，只点「跳过」「关闭」或 X
3. 冷启动默认落在**首页**。目标入口可能直接就在首页金刚区，**先在首页找一轮，找不到再切「我的淘宝」**
4. 底部 Tab 通常五个：首页、视频/逛逛、消息、购物车、我的淘宝。「我的淘宝」只是兜底入口路径

## 入口寻找顺序：首页直入优先（2026-10-15 实测有效）

冷启动停在首页时，**先在首页找入口，命中就直接进，不用切「我的淘宝」Tab**。实测（华为 LIO-AN00，屏 1176×2400）：首页搜索栏正下方的金刚区第一屏就同时有「领淘金币」和「芭芭农场」两个入口。

### 首页金刚区锚点（首页首屏，y≈343 一行）

- 「领淘金币」：content-desc `label="领淘金币"`，容器 FrameLayout `at=28,343 191x201`（中心 ≈ 123,443）
- 「芭芭农场」：content-desc `label="芭芭农场"`，容器 FrameLayout `at=640,343 191x201`（中心 ≈ 735,443）
- ⚠️ 这两个入口在可访问性树里是 **content-desc（`label=`），没有 `text=`**——匹配锚点时必须同时看 label 和 text 字段，只 grep text 会漏
- 金刚区不在首屏时向下滑 1~2 屏再找；**最多滑 2 屏**，再往下就是商品推荐流，找不到就放弃首页路线

### ⚠️ 首页点击的坑（实测 2026-10-15）

- **金刚区入口有两层完全重叠的同 label FrameLayout 节点**，ref 点击会点偏——实测对 `label="芭芭农场"` 的 ref 点击落到了「天猫汽车」小程序。**首页金刚区一律用坐标点击**（取上面标注的容器中心），点完立刻 list 校验落点
- 首页下半屏是商品 feed 和「立即领取」优惠券横幅（`homepage_pop_view`），**只允许点 label 精确等于「领淘金币」/「芭芭农场」的元素**，禁止点商品卡、红包横幅或任何模糊匹配的文案

### 落地页校验（首页直入后）

- 点「芭芭农场」→ 落地页应为 `WebView text="芭芭农场"`（TMS 容器，`tms_fragment_container`），页内找「**集肥料**」（实测 `Button text="集肥料"`）
- 点「领淘金币」→ 落地页应为 `WebView text="淘金币首页"`，页内找「**赚更多金币**」（实测大按钮 `text="赚更多金币"`；两侧还有「玩游戏」「找好友」入口，**不要点**）
- 落点不对（落进天猫汽车 / 其他频道页）→ BACK 回首页重试一次；连错 2 次放弃首页路线，改走下方「我的淘宝」路径
- 这两个落地页右上角有「返回首页」按钮（`id=back_home_btn`），需要回首页时可以用它，比连按 BACK 稳

## 芭芭农场

路径 A（首页直入，优先）：

1. 停在首页，金刚区找 `label="芭芭农场"`（y≈343 一行，找不到向下滑 1~2 屏）
2. 按容器中心**坐标点击** → list 校验落到 `WebView text="芭芭农场"`
3. 点「**集肥料**」（同义锚点：「做任务」「去集肥料」「肥料任务」）→ 弹出/跳转到任务列表

路径 B（我的淘宝，兜底）：

1. 底部 Tab 点「我的淘宝」
2. 在「我的淘宝」页向下滑 1~2 屏，寻找含以下文案的入口：
   - 「芭芭农场」
   - 「农场」
   - 副标题含「免费领水果」「种水果」「浇水」
3. 点击进入 → 等待 H5 容器加载（`sleep 3`，必要时再来一轮）
4. 进入后点「**集肥料**」→ 任务列表

任务列表页特征锚点：「集肥料」「今日任务」「浏览 XX 秒」「去浏览」「已领取」「去完成」。

## 淘金币

路径 A（首页直入，优先）：

1. 停在首页，金刚区找 `label="领淘金币"`（y≈343 一行，找不到向下滑 1~2 屏）
2. 按容器中心**坐标点击** → list 校验落到 `WebView text="淘金币首页"`（页内还能读到金币余额）
3. 点「**赚更多金币**」→ 打开任务列表

路径 B（我的淘宝，兜底）：

1. 底部 Tab 点「我的淘宝」
2. 寻找含以下文案的入口：
   - 「淘金币」
   - 「金币」
   - 副标题含「签到」「领金币」「当钱花」
   - 也可能在顶部「我的资产」区域或「更多工具」九宫格里
3. 点击进入 → 等待加载
4. 进入后点「**赚更多金币**」→ 打开任务列表

任务列表页特征锚点：「赚更多金币」「每日任务」「浏览 XX 秒」「去浏览」「签到」「已领取」。

## 找不到入口时的降级路径

按顺序尝试，任一环节成功即停止（入口来源记在首个任务的 `--note` 里，方便复盘首页直入命中率）：

1. **首页金刚区**：停在首页，按上方「入口寻找顺序」在首屏及下滑 1~2 屏内找「领淘金币」/「芭芭农场」
2. **我的淘宝**：底部 Tab 切「我的淘宝」，往下滑 1~2 屏，入口可能藏在「更多工具」九宫格第二页
3. **展开更多**：若「我的淘宝」页面有「更多」「全部工具」「查看全部」，点开后在九宫格里找
4. **搜索兜底**：回首页点顶部搜索框 → `mobile_type_keys` 输入「芭芭农场」或「淘金币」（带 `submit: true`）→ 在结果中点对应的官方卡片 / 「立即进入」按钮
5. **放弃**：以上都失败 → 记录「入口未找到 + 当前页面元素摘要」，跳到下一个模块。不要用 `mobile_open_url` 拼不确定的 scheme

## H5 容器注意事项

两个模块基本都是 Webview / 小程序容器，因此：

- `mobile_list_elements_on_screen` 可能只返回少量元素甚至只有根节点；此时配合 `mobile_take_screenshot` 用坐标点击
  - 但先分清：**「只返回根节点」多半是页面还没渲染完**，多等一轮再 list 通常就完整了。2026-10-14 复测，淘金币 H5 首页（Themis/TMS WebView 容器）的 dump 是完整的——`@e36 WebView text="淘金币首页"`、余额 `text="1137594"`、入口按钮 `text="赚更多金币" at=300,585 576x150` 都能直接读到，不需要截图。
  - 真正需要截图的是**任务列表弹层内部滚动**（`fissionOverlayPortal`）那一种，见 `mobile-mcp-playbook.md` 的「dump 过期的确切边界」。
- 加载期间的症状：白屏、只有标题栏、元素列表为空 → 等待 3 秒后重试，最多三轮
- 容器内的返回箭头点不动时，改用 `mobile_press_button` BACK
- 页面可能自动弹出「领取今日奖励」「开屏福利」浮层 → 找 X 关掉，**不要**点浮层中心的按钮（多半是「去下单」「去抢购」）

## 回到任务列表

完成一个任务后：

1. 连按 BACK，每按一次 list 一次，判断是否出现模块锚点文案；**锚点同时接受首页层**：`WebView text="淘金币首页"` / `WebView text="芭芭农场"`（回到模块主页，再点一次「集肥料 / 赚更多金币」即可），或首页金刚区 `label="领淘金币"` / `label="芭芭农场"`（回到首页，按入口寻找顺序重进）
2. 回到哪一层就按哪一层的路径重进，不要执着于「必须回到任务列表弹层」——从模块主页点「集肥料 / 赚更多金币」和从首页直入是等价的
3. 最多 5 次；超过则 `mobile_launch_app` 重启淘宝，停在首页按「入口寻找顺序」重进
4. 注意：重进后列表可能已重排，重新 list 再继续
